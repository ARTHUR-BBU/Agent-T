# Claude Code 交接：合同账户隔离开发前

日期：2026-11-10。用户要求完成规则和用户管理，在本机测试，暂不部署；开发需独立审核。

当前账户试验使用独立数据库、独立 Cookie 路径，合同及报告、对话、异议和修订等接口仍使用无所有权的共享审查库。新旧账号均不能被视为已保护合同；现存无主记录不得自动归属任何人。账户会话撤销与合同写入分在两个 SQLite 数据库时，先鉴权再写入不能保证并发撤权的一致性。

本轮先建立同库事务下的合同所有权基础，账号和合同写入必须在同一 SQLite 事务核验；旧行保持无主，管理员不自动拥有个人合同。此前的本机试验接口及实际合同入口不会因此自动获得保护。待覆盖所有合同与衍生接口、后台长任务和并发撤权，完成独立审核和迁移策略，才能启用多用户合同隔离。

最近稳定代码的全量测试为 1750 passed、34 skipped；本轮修改后的结果须重新验证。保留现有工作区及 `trial-db/`，不部署。
