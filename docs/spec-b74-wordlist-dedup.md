# B7-4 小批施工卡：禁语表扩样（老钱 18 词）+ 牵连摘录同条款去重

> 性质：两项老挂账打包小批（B7-1 挂账②禁语扩样 + B7-2 挂账①摘录窗口
> 去重）。法务裁定：老钱 2026-11-04 意见书（全文见 §附录，可直接执行）。
> 费用：零 LLM 新调用（纯代码+离线测试）。合并后**需一次生产换装生效，
> 另行请示**。

## 一、目标

1. **禁语表扩容 +18 词**（老钱「放行操作词×签署动作词」双锚结构裁定，
   覆盖 B7-2 五题考试漏报形态：同义换词/语序变体/程序催办）
2. **牵连摘录同条款去重**：同一条款多命中合并为一条，摘录窗扩到条款
   全段（根治 I1 考题实锤的「半截话+下一条款起始残片」近重复形态）

## 二、非目标（明确不做）

- 不引入语义模型做第一道拦截（确定性/零成本/误杀可控三优先级不变，
  老钱裁定重申）
- config/scorecard_forbidden.yaml **不动**（评分卡 A 类与起草表
  BANNED_PATTERNS 两表独立维护、各自命中各自拦；「可放心签署」在
  起草表补入不构成与 A 类重复）
- 系统提示词不改（build_system 第 1 条已含「含委婉形态」表述）
- 不同条款摘录各自保留（现状不变）

## 三、施工方案

### 3.1 禁语表（app/prompts/revision_prompts.py）

BANNED_PATTERNS 追加 18 词（老钱清单原文，含双锚结构注释）：

- A 替用户拍板类（7）：按此签署/照此签订/按本版签署/推荐签署/
  推荐采用并签订/建议尽快签订/宜尽快签署
- B 暗示条件已满足类（7）：已满足签署前提/满足签约前提/符合签署
  条件/不存在签署障碍/无签署障碍/签署无障碍/签约无障碍
- C 消除疑虑类（4）：可放心签署/放心采用/无需顾虑签署/无需修改即可
  签署

**不拦边界（防误杀用例，测试锁定）**：签署前建议咨询律师/签署前提
尚不明确/建议签署前完成定金条款修改/本合同自双方签署之日起生效
（裸「签署」「生效」永不命中——双锚结构天然收窄）。

**局限声明**（写进代码注释）：词表是确定性字面拦截的下限，不是完备
语义边界；对抗测试漏网话术一律回填词表并回归验证；未命中≠合规，
逐例语义核对兜底。

### 3.2 摘录去重（app/services/impact.py find_related_clauses）

- 同条款多命中 → **合并为一条**，摘录窗=条款全段（按命中 pos 反查
  clause_id 取 [start,end)，clause_index 已在签名中）；keyword 改为
  **数组**（合并命中词逐一保留）；position 取条款起始
- **条款全段有明确长度上限**（codex #170 复批收紧）：新增常量
  `_EXCERPT_MAX_CHARS`（施工时定值，预估 300 字符量级，测试锁定），
  超长截断落在条款边界语义完整处+标注「摘录截断」，同一被截条款
  允许按截断段出多条（物理限制非语义判断）——**「全段」不是无限制**
- **真实入口安全门不变（codex #170 复批 P1-2，防误读）**：
  analyze_impact 对缺条款索引/无法定位原条款范围**继续返回受限
  未覆盖（missing_source），不调模型不扣额度**——这是此前防「原条款
  误当关联条款」的修复，本次不撤。辅助函数的「无索引降级桶去重」
  仅指辅助函数自身行为的兜底（不绕过入口门禁的场景），**并以真实
  入口级测试锁定**：缺索引上传→analyze_impact→断言 missing_source
  零 LLM 调用（复用 B7-2 I2 同款断言）
- 不同条款各自保留（现状）
- 消费方兼容：findings pairing 用 len(excerpts)（不变）；前端/报告
  渲染只用 excerpt 字段（keyword 数组只进 payload，渲染层零改动——
  施工时复核 state 路由与 report 组装不消费 keyword）

## 四、测试清单

- 禁语三件套（老钱要求）：旧 11 词回归 + 新 18 词命中（每词一条
  降级断言或代表性抽样+全词存在性断言）+ 边界不误杀 4 例
- 摘录正反例：同条款两命中→1 条全段窗（含 keyword 数组合并）/
  不同条款→2 条 / 超长条款截断+标注 / **入口级：缺索引→
  missing_source 零调用** / findings pairing 对齐
- **字面过滤局限重申（codex #170 复批）**：禁语表是字面过滤，测试与
  文档不得声称挡住所有同义话术；局限声明原文已在 §3.1
- 既有回归：test_b72a 委婉形态降级断言、B7-2 I1 形态复现用例
  （两命中同条款→1 条）
