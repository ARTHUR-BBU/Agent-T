# Claude Code 开发后交接：账户绑定审查任务

新增内部服务 `app/services/owned_review_jobs.py`：在同库事务中创建合同和绑定所有者、会话摘要、随机工作凭证摘要的任务；提交结果时复验当前会话、所有者、任务凭证、租约、合同 TTL 和原始状态，结果字段受白名单限制。并发终态只允许一次成功。`reap_stale` 在显式调用时回收失效会话、租约或到期合同；合同删除时级联任务记录。初始化严格验证任务表 DDL、外键和数据完整性，未知旧表拒绝并需离线迁移。凭证明文不写任务表。

独立审核发现的合同 TTL、清理外键、旧结构约束及合同先于租约到期问题已修复并补测试。账户任务和只读接口专项 15 passed（32.40 秒）；Ruff 通过。账户任务尚未接 HTTP、实际 worker 或模型出站；没有租约续期和自动调度，单个损坏任务可使一整批回收回滚。尚未验证真实撤权/提交/回收竞态、超过 100 项分批和旧共享路径数据清理，禁止称为完整账户隔离或可供真实合同使用。用户停用只能阻止后续写入，已经出站的模型请求不可追回。未做全量回归，未部署。

下一步：实现不会写旧全局库的账户后台工作器、为每次模型出站与结果持久化接入任务授权，处理长任务续租、撤权、崩溃与异常回收，再贯通用户上传及所有合同衍生接口；随后完成可信完整规则回归、具名发布和回滚。
