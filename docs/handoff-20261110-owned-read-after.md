# Claude Code 开发后交接：账户合同只读试验

新增默认关闭的 `CONTRACT_ACCOUNT_READ_TRIAL=1` 本机只读 API：`GET /api/local-accounts/contracts` 及 `GET /api/local-accounts/contracts/{id}`。需同时配置本机账户试验，账户试验库必须不同于旧全局审查库。该库须事先由离线受控流程建立账户、审查和 owner schema；接口以 SQLite 只读方式在同一事务中校验会话、CSRF、所有者和 TTL，先过滤所有者再分页。无主、过期及其他账户记录不可见，管理员无默认旁路；详情包含合同预览和条目证据，只可使用合成数据。处理过的错误、意外错误及成功响应均使用 no-store；连接设置 trusted_schema=OFF。

本机自动化：账户只读、账户接口与规则执行专项共 14 passed（21.44 秒），Ruff 通过。独立审查看过代码及风险，并指出：读取事务的快照建立后若账户同时被撤销，在途读取仍可能返回；未覆盖真实并发撤权。接口不处理上传、报告、对话和旧路由，仍无法保护实际合同；试验库不得被其他旧服务同时作为共享合同库访问。SQLite 文件本身的本机权限另需保障。首次响应已开始后如果发生错误，中间件重新抛出，不尝试发送第二个响应。未做全量回归、未部署。

继续工作：确定在途撤权语义并覆盖竞态，设计真实应用的同库迁移与旧路由封闭，接入全部合同及衍生接口和后台任务，再验证双账户全流程；完成候选完整回归证据、具名发布和回滚。现有 capability 仍明确 protects_contracts=false。
