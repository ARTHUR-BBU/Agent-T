# Claude Code 开发后交接：账户模型 transport 接线

默认关闭的进程模式 `OWNED_LLM_EXECUTION=1` 已接入 `llm_client.chat_completion` 和 `decision_judgment`。账户任务上下文缺失、账户/任务失效、账本故障、模型与 payload 不一致或目标不在允许名单时拒绝；HTTP 直连禁用环境代理和重定向，Cloudflare 账户需在进程启动前通过 CF_ACCOUNT_ID 明确配置并与 URL 一致。模型、供应商、节点目前为受限固定集合；自定义模型和 TypeSafe 不支持。模式在模块导入时固定；账户模式下禁止访问旧共享 llm_calls。

每次发网前专用账本核权并登记，响应协议校验后重新核权结算；账户分类业务另记 business_outcome，区分 transport 成功与业务解析失败，不存原始输出。账户旧调用账本 schema 因新增字段发生变化，旧试验库需离线迁移，当前初始化拒绝旧结构。主要模型层、预审、分类、质量、异议、问答、修订和 pipeline 已透传专用异常；账户模式禁止常见自定义 chat_fn。模拟 HTTP 测试覆盖两类入口、无上下文、目标伪装、模型不一致、账户停用、旧库不写、异常结果、线程上下文和真实分类解析；未向真实供应商发请求。

验证：相关专项 125 passed（44.67 秒，最后目标绑定修改前）及最终完整回归 1830 passed、34 skipped（908.79 秒，退出码 0）；账户模式使用模拟 HTTP，完整回归以默认共享模式启动。独立审核后已补 payload 模型与受信 Cloudflare 账户检查。账户模式网络故障当前不保留旧分类瞬态重试语义；分类以外的业务解析结算、跳过记录和旧账本查询尚未接入。检查释放锁与实际发送间仍可能撤权，已发送数据无法追回。

关键未完成：账户后台 worker、上传/预审前建任务、进度/关联数据和所有旧合同路由的账户隔离、用户界面、调用恢复与费用留存、真实网络和生产安全验证；正式规则发布回滚仍未完成。不得将此模式供真实合同或生产使用。未部署。
