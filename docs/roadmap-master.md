> 版本 v1.0（2026-09-22）。本文档是项目的**总施工图**：回答「整个项目什么时候是阶段性头」「每一批从何而起、在什么位置」。

## 一、项目的终点（什么叫「阶段性头」）

**v1.0 = 一个中小企业法务能放心用的合同审查闭环工具**，验收画像：

1. 上传合同 → 预审分诊 → 规则逐条核查 → AI 增强（评分卡/补盲/质量观察/事实材料/有界核验）→ 异议层 → **修改建议（A/B/C 三版）→ 连带影响提示 → 报告导出**——全链走通
2. 全链证据可追溯：每条结论能回答「依据哪条原文、哪个主张、谁做的决定」（证据法三层引用化的终点）
3. 治理闭环：宪法 + 规范 + 门禁 + 外审常态化的工程纪律跑得住
4. 上线条件：HTTPS + 域名（备案后）、真实品类语料持续校准机制

到 v1.0 之前的所有批次，都能在下面第三节的清单里找到编号和位置。

## 二、为什么有两条线（总图的由来）

```
主线（盖楼）：2026-09-09 定稿的深化路线图 v1.0（roadmap-llm-ui.md）
  阶段0 地基 → 阶段1 看得全 → 阶段2 质量层 → 阶段3 异议层 → 阶段4 改得有用

加固线（承重墙）：2026-09-14 起由 ChatGPT 三轮外部审计触发
  外审整改批1/2/3 → 宪法治理（28条+LLM规范）→ 证据法批1 → 批2a → 2b-①②③ → 2c
```

两条线的关系（盖房比喻）：主线是**盖楼**（一层层加功能）；加固线是**质检站查出了承重墙钢筋问题后的加固工程**——2026-09-14 第三轮外审判词「证据从输入到展示的完整链条尚未形成统一约束」，宪法第十六条（Single Evidence Fact）要求「后续层引用而非重新搜索」，证据法批 1/2 就是这条宪法条款的施工落地。**加固线插队的原因：阶段 4「改得有用」要生成修改建议，每条建议必须能回答「基于哪条证据、哪条主张」——不先有证据引用化，阶段 4 就是空中楼阁。**
