# 给 Claude Code 的开发后交接

## 已完成的本机试验

规则执行试验默认关闭。仅显式设置 RULE_EXECUTION_DB_TRIAL=1、ACCOUNT_LOCAL_ENABLED=1 并提供已有独立 ACCOUNT_DB_PATH 才进入试验；仅限环回地址、同源写请求。页面提醒合同尚未按账户隔离，只能使用合成测试数据。品类列表、规则目录和新上传审查从数据库活动版本读取；提交时固定规则快照及版本、代次和完整 SHA，运行中的审查不会随指针切换改变。被禁用条目不进入新审查。

品类确认票据一次性绑定合同摘要、输入类型、类别、立场和规则版本；它仅在当前进程内有效，未绑定用户或浏览器，重启或多进程可能要求重新提交。文件模式保留原有行为。详见 app/services/rule_execution_trial.py、app/services/rule_trial_confirmation.py 和 app/api/routes.py。

账户、规则候选、具名审核仍属于本机试验能力。正式发布与回滚的完整授权接口、真实完整回归证据和合同数据账户隔离尚未完成；不能将数据库试验说成生产发布。规则快照 SHA 不代表整个应用构建或所有相关配置的完整指纹。未部署。

## 数据库注意事项

独立审核及部分早期测试可能在未设置隔离 STORE_DB_PATH 时导入应用；导入会触发默认审查库中断任务处理。只读检查发现默认库 342 条记录、处理中 0 条、14 条带服务重启中断文案；缺乏变更时间，无法确定来源或是否由本次操作造成。数据未删除或重置。之后运行测试前必须在启动进程前设置独立临时 STORE_DB_PATH，避免触及用户数据。

本轮后端专项曾通过 104 项；最终结果及未验证边界以本次 Codex 最终回复为准。继续完成真实用户与合同隔离、可信完整回归证据、具名正式发布与回滚，并由独立审核验证后，才可评估生产上线。
