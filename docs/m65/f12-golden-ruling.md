# F-1/F-2 金标裁决意见书（法务老钱，2026-09-28）

> 出具：法务老钱，2026-09-28。依据：docs/m65/f12-golden-brief.md、run2-report.md、f12-run1.json / f12-run2.json、config/checklist_procurement.yaml 现行版。
> 本裁决只定标准，不动代码与 YAML；修复施工由开发狗按本金标出设计稿过审后再动（问题单第 6 条：确认此流程，YAML 词表改动属行为改动，须测试合同集回归）。

## 一、逐条裁决（坐实 / 不坐实 / 待复核）

### 1. 价款与支付 ×9 —— 全部坐实
理由：现行 payment 项 pass 词表只有「质保金 | 验收合格后支付 | 分期支付 | 验收后付款」四条（checklist_procurement.yaml:170-175），写的是**风险政策词汇**而非「付款条款存在」词汇。而引擎的真实语义是「pass 未命中即未找到」（租赁意见书 §一 L-2 已备案）。于是任何一部**正常约定付款节奏**的合同（收到发票后 X 个工作日内付款、按月结算、支付报酬）都会被判「未找到」。这不是措辞边角案例，是 pass 词表的结构性错位：它筛的是「付款安排好不好」，却被用来判「有没有付款条款」。
9 条（新疆食材、校服、农副产品、水泥、建设施工、能源托管、委托、生鲜乳、承揽）原文全部存在明确的金钱给付安排，属「该找到而没找到」，无一例外。

### 2. 期限 ×5 —— 全部坐实
理由同构：term 项 pass 词表只有「\d+日内 / 工作日内完成交付 / 完成送货」类交付口径（yaml:184-192）。而「一、合同期限」「供货服务期＿年」「履行期限」「有效期」「交付期限」是教科书级的存续期/履行期表述。金标：凡出现合同存续期或履行期表述（含日期区间式「自…至…」），不得判未找到。

### 3. 标的 ×4 —— 三条坐实、一条待复核
- 新疆食材（材料名称仅在表格）、承揽（承揽项目在表格）：坐实，归因表格路径（见第 4 条裁决）。
- 能源托管：坐实，且暴露第二层问题——subject_matter 的 pass 词表（型号/规格参数/配置清单/技术参数/产品规格，yaml:94-99）是**办公设备味**的词表。服务类合同（能源托管、委托、数据加工、承揽）的标的是服务工作成果，天然没有「型号」，按现词表永远未找到。
- 水泥 GF-2008：**待复核**。判定产物本地分析无任何标的信号命中，但 GF-2000/2008 体例的品名/规格几乎必然在表格里。若表格文本抽取修复后重测仍无信号，再改判不坐实。挂表格专项验收清单。

### 4. 表格条款是否要求命中 —— 金标要求：必须命中
法理：《民法典》第 469/470 条下，表格是合同书面形式的组成部分，条款效力不因载体是正文还是表格而异。GF-2000 承揽、GF-2008 买卖把价款/标的/数量放表格是官方示范文本的标准体例，不是边角。产品声称「对合同打标」，就必须对表格条款一视同仁；判不了就是漏报，需要表格路径专项，**不认可把表格划出边界**。
现成证物：商务合作 NDA 的「知识产权」pass 词命中条件（知识产权）在本地源文件实锤存在，引擎却判未找到——pass 词表含「知识产权」（yaml:243），唯一解释是引擎匹配文本不含表格内容。请开发狗以此为第一排查点。

### 5. 老式模板（2000/2008 体例）—— 单列适配批，不写入「不支持」边界
理由：①SAMR 示范文本库 2000-2016 版仍在被大量企业直接使用，真实用户拿来的合同很可能就是老体例，明示不支持等于把最高频用户场景划出产品；②其漏报根因（表格化、留白空格破坏正则、无编号导致条款切片失效）与第一批通用修复同源，先修通用路径会顺带治愈大半；③「划出边界」必须是最后手段，且回测数据说话：第一批+表格专项修复完成后回测，若 claim_id 率仍 <0.3 且漏报仍集中，再对**单项**设「体例降级提示」（报告层标注，非整体拒审）。不同意现在就写「不支持三代前体例」进产品边界。

### 6. F-2 对等量词豁免 —— 裁决：作为前置豁免门，但限定双重条件
法理本体：「任何一方对由于不可抗力造成的不能履行不承担违约责任」是《民法典》第 180 条、第 590 条不可抗力免责的普通复述，双方对等，逻辑上「单方」要件根本不成立——判定「单方免除」至少要求免责义务主体**特定指向一方**。全称量词（任何一方/双方/各自/双方均/彼此）直接否证「单方」。
豁免门（两个条件同时满足才豁免）：
1. **邻域限定**：对等量词出现在免责命中句内或紧邻一句（沿用 ±300 字符邻域口径），**不做全文级豁免**——「双方」在正文必现，全文级豁免会把真单方条款全部洗白，这是外审 #88 担心的镜像，同样适用；
2. **免责事由限定**：同一句内须有免责事由词（不可抗力|情势变更|政府行为|自然灾害|疫情|法定免责语境）。无免责事由的裸「任何一方不承担违约责任」不豁免（现实中罕见，漏报优先）。
另发现一处叠加 bug，一并裁决：建设施工 GF-2017 引用的 17.4 原文是「**不**免除其违约责任」——这是**加责**表述却命中了「免除.{0,8}违约」。金标补否定豁免：命中词处于「不免除|不得免除|不视为免除|并未免除」否定语境的一律不触发。农副产品与委托合同的「以部分或者全部免除相应的违约责任」（不可抗力举证条款）同属对等+法定事由，落豁免门。

### 7. F-4 签署与印章（示范文本口径）—— 裁决：放宽，等价组扩两行
「盖章栏 + 法定代表人：/授权代表：落款行」构成法人缔约的完整签署配置，判需关注是误报。法理同租赁裁决二（民法典 490 条签署方式三选一等价）：盖章对应法人，落款行落到有签字权的自然人，两件齐备即要件完整。
等价组扩入：法定代表人[:：]|授权代表[:：]|委托代理人[:：]（与盖章语境同现时）。边界不松：全文只有「（盖章）」孤行、无任何自然人落款行 → 维持需关注；连盖章栏都没有 → 未找到。空白留白模板整项判未找到属合理（无内容可审），**不作为漏报统计**，建议报告层加「空白模板」旗标。

## 二、金标定义（供规则修复直接引用）

**「未找到」金标语义**：全文（含表格文本）确无该类内容，方可判未找到。判定语序保持 need_attention → pass → missing_as，故修复主战场在 pass 语义域。

1. **价款语义域**（payment pass 扩展）：标的词（价款|货款|报酬|服务费|服务费用|租金|对价|合同总价|合同金额|结算）∧ 给付动作（支付|付款|付清|结清|支付给|结算）或金额元/人民币表述 → 不得判未找到。按现行风险模式（背靠背、签约即付、无质保等）照旧判需关注，两不相扰。
2. **期限语义域**（term pass 扩展）：合同期限|履行期限|交付期限|供货(服务)期|服务期|有效期|租赁期限|租期|工期|期限 ＋「自…年…月…日至…止」日期区间式。
3. **标的语义域**（subject_matter pass 扩展）：在现词表上加 品名|材料名称|货物名称|标的物|标的|项目名称|承揽项目|服务内容|服务范围|工作内容|质量标准|技术标准（服务类合同由此脱困）。
4. **保密**：正文或表格出现「保密」义务性表述（保密条款|保密义务|保密责任|应当保密|负有保密）即不得未找到；裸标题+内容算覆盖。
5. **知识产权**：语义域为 知识产权|专利(权)|著作权|版权|商标|成果归属；表格内命中同有效。
6. **F-2 豁免门**：〔对等量词 ∧ 免责事由词，均在命中句±邻域〕→ 豁免；〔否定前缀 不/不得/并未 + 免除〕→ 一律不触发。真单方召回保护：主体特定写法（乙方不承担违约责任、免除甲方责任而乙方不免责类）不含对等量词，不进豁免门，照旧必中。
7. **签署等价组**：盖章栏+（法定代表人|授权代表|委托代理人）落款行 → 通过；纯盖章无自然人行 → 需关注；全无 → 未找到。

**对抗样例金标三件套（小智娘写断言用）**：
- F-2：①「18.2 任何一方对由于不可抗力造成的部分或全部不能履行合同不承担违约责任」→ 违约责任不得以单方免除标需关注；②「乙方逾期交付的，免除乙方全部违约责任」→ 必须需关注；③「部分或者全部免除违约责任，但迟延履行后发生不可抗力的，不免除其违约责任」→ 不得命中。
- 价款：「甲方收到发票后＿个工作日内将上月采购款支付给乙方」→ 不得判未找到。
- 签署：「供方（盖章）：法定代表人：____」→ 不得需关注；「（盖章）」孤行 → 需关注。

## 三、修复批次建议

**第一批（先修，通用收益最大）**：①F-2 对等量词豁免门 + 否定豁免（误报直接烧信任，且损伤评分卡公信力）；②价款/期限 pass 语义域（一个批次清 14 条漏报）；③签署等价组扩两行（F-4，7 中 5 触发的误报面）。注意：F-1 的未找到不是外观问题——按既有口径未找到触发 89/74 封顶，正常官方示范文本被冤枉扣分封顶，杀伤大于单条误报。
**第二批**：④表格文本抽取专项（标的/保密/知产 + 老体例 claim_id 率低的共同根因；先以商务合作 NDA 知识产权条为证物定位引擎是否真不读表格）；⑤标的语义域服务化扩展。
**缓修/挂账**：⑥老体例专项——第二批复测后再评估是否需要单项降级提示；⑦水泥标的待复核——表格专项验收时自动重测裁决。
**明示不修**：空白留白模板的全项未找到（合理行为），仅加报告层「空白模板」旗标。
