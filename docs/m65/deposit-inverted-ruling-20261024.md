# 法务老钱裁定书｜定金倒序词表（B7-0 前清批，2026-10-24）

> 回应挂账「需法务老钱定夺」（docs/plain-changelog.md 挂账总账：定金倒序词表）。
> 施工：PR #145（b7-0-prework）config/checklist_procurement.yaml unfair_terms 项。

## 裁定一：倒序分支词形范围

认可进直捕词表的倒序形态（与正序放同一 any_of 组，共用 unless）：

  (没收|不予退还|不予返还|无权要求返还)[^。；\n]{0,20}定金

1. 动词集与正序严格对齐：没收 / 不予退还 / 无权要求返还，三词原样镜像。
2. 另补「不予返还」（正反两序都加）：「返还」是民法典 587 法定用语，
   「不予返还定金/定金不予返还」在卖方格式合同里不比「不予退还」少见。
   核过现行 yaml，正序词表也没收「不予返还」——属同一漏报面，本批一并补。
3. 修饰间隔与正序一致 0-20 字；句界阻断符一致（。；\n），跨句不命中。
   法律依据：定金丧失效果必须以「定金」为直接宾语；跨句后「没收」的宾语
   指向不可控（可能是货物、保证金、样品），跨句命中无法律语义支撑，不收。
4. 「退还定金」（中性退还）正倒序皆不入词表：「合同解除后退还定金」是正常
   清算安排，不是罚则。
5. 「定金没收」（定金在前间隔 0）正序已覆盖，不重复设。

## 裁定二：授权翻转面验收口径

1. 允许翻转的唯一判定语义：合同存在定金没收/不予退还/无权要求返还条款
   （正倒序任一），且全文无对称罚则豁免 → unfair_terms = 需关注，为正确翻转。
   依据民法典 586/587：定金罚则双向对等；仅约定交付方丧失定金而不约定收受方
   双倍返还责任的，属明显单方偏向，与 pc11 金标同构。
2. 倒序+对称罚则并存句**无需新增豁免分支**。现行 unless 是文档级 any_of，
   「双倍返还…定金」「定金…双倍返还」的分句内绑定形态本来就与方向无关：
   倒序命中只要全文存在绑定对称罚则即被豁免，含跨句并存（「甲方有权没收定金。
   甲方违约的，应双倍返还定金」）——豁免以绑定出现在同一分句为准，与命中句
   是否同句无关。施工时只需补一条该形态的验证测试，不要改 unless 结构。
3. 授权翻转白名单（17 份官方语料+回放卷验收标准）：
   - 允许：含倒序单方定金没收条款的卷，unfair_terms「未找到→需关注」，且 hits
     新增含「定金」的命中词；
   - 允许：pc11 的 hits 新增倒序命中（状态本就需关注；判别性锁测试断言
     「存在含定金的命中」，正倒序任一满足即过，不回退）；
   - 允许（非翻转）：倒序命中+对称罚则并存 → 维持非需关注；
   - 白名单之外零翻转：其他条目、其他文档、其他状态变化一律记回归失败；
   - 每笔翻转须点开原文人工确认是「定金被没收/不退且无对等罚则」语义、动词
     与「定金」在 0-20 字内同句，否则记误报退回。

## 裁定三：误伤护栏与反例 fixture

倒序分支必须与正序共用同一条 unless 豁免链——实现上放进同一 any_of 组即自动
继承，禁止单开无豁免的倒序规则。必备反例/正例 fixture 六件，每件带判别性断言
（参照 tests/test_audit2_batch3.py 正序锁写法——删掉分支必须炸）：

1. 对称罚则倒序并存：「乙方中途解约的，甲方有权没收定金；甲方违约的，应双倍
   返还定金。」→ 不得因定金子规则判需关注；
2. 货款双倍返还反例（外部审计 P1-2 反例的倒序版）→ 豁免不得被无关「双倍返还
   货款类」句触发，仍需关注；
3. 中性退还：「合同解除后 5 日内，甲方应退还定金。」→ 不得命中；
4. 宾语非定金：「乙方违约的，没收履约保证金。」→ 不得命中；
5. 句界阻断：「甲方有权解除合同并没收乙方预付财产。定金于签约日支付。」→ 不得命中；
6. 正例判别性锁：单方倒序没收独立成文（pc11 同构句）→ 需关注且 hits 含「定金」。

观察项（不阻塞本批）：unless 的 ±60 字符窗口化豁免（在案 P3-1）对倒序分支同样
生效，无关句「双倍返还」落窗内可能误豁免单方没收——属既有挂账面，待句界截断
改造一并收敛，本批不扩权处理。

立场照旧：以上是风险提示规则的专业标准；产品输出措辞仍是「该条偏向某方，请
自行留意」，不给签署建议。
