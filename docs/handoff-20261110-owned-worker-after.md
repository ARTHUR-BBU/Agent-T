# Claude Code 开发后交接：账户审查工作器

新增内部 `OwnedReviewWorker`，在账户模式、独立账户库运行真实 `run_review`：任务创建时绑定服务器计算的输入 SHA256 和立场；认领时同事务校验身份、任务凭证、输入摘要及数据库活动规则版本，并用唯一认领记录防重复执行。规则版本与立场写入审查记录，管线在账户模型上下文执行，结果只通过账户任务的事务接口保存；保留规则包和证据索引。未提供 HTTP 上传入口，不供真实合同使用。

独立审核发现并修复：账户模式启动时旧共享 store 不再初始化；ReviewStore 和 AccountStore 在打开前核验冻结账户路径及共享库边界，账户库不执行旧 processing 恢复；通用账户记录修改对绑定元数据使用深拷贝比较，防止嵌套篡改。账户模式试验库须在进程启动前通过 ACCOUNT_DB_PATH 指定，并与 STORE_DB_PATH 不同；这一模式尚未封闭所有旧接口和直接数据库访问。

验证：账户工作器、账户 transport 和账户 API 专项 19 passed（84.32 秒，后续仅调整测试子进程环境）；最终独立子进程管线/共享库/绑定专项 3 passed（16.02 秒），Ruff 通过。子进程以启动前账户模式设置、虚构合同和 fake HTTP 实际运行 LangGraph，检查账户账本有调用且独立共享路径未创建。pytest 报一条既有 LangChain/Pydantic V1 与 Python 3.14 兼容性警告。没有真实供应商调用；前次全量回归为 1830 passed、34 skipped，本轮代码变更后未重跑全量。

尚未完成：账户上传/预审入口、页面、所有旧合同和衍生接口隔离、账户后台调度/租约续期/异常恢复、授权失败与进度处理、模型在途撤权和真实费用留存；工作器仍是内部同步方法。测试 fake 模型输出不证明模型质量；实际共享库已有数据的全路径并发保护仍需验收。正式规则发布、回滚仍未完成。未部署。
