# 租赁品类保密四态回填 · 设计稿 v0.1（双件套）

> 依据：老钱裁定残-1（docs/m65/residual-ruling-20261022.md，2026-10-22）。
> 纪律：设计稿过审后才写租赁代码；门禁=「翻转白名单」口径，非「零翻转」字面。

## 〇、任务简介（给用户）

租赁合同的官方示范文本里有一个「保密要求」栏目（实锤：租赁回放第 1 卷第十二条）。
现在租赁审查器不查这一项——这是盲区。老钱裁定：把已经在采购/NDA/技术服务三品类
跑通的「保密四态」判定搬进租赁，但要按租赁的法律性质做三处改造：①否认保密不算
红线（租赁的保密是附带约定，不像 NDA 是命根子），只列普通「需关注」；②卷面上
压根没有保密栏目的，判「本类不适用」而不是「未找到」——否则大多数住宅租赁会被
冤枉扣分（老钱原话：封顶冤案杀伤大于单条误报）；③「约定的其他保密信息即___」
这种义务句完整、只是扩展栏留白的，判通过。验收门禁：15 份回放卷里只允许第 1 卷
新增一个「通过」判定，其余 14 份判「本类不适用」，全部既有结论零翻转。

## 一、任务设计（给审计）

### 1.1 回填内容（checklist_lease.yaml 新增第 15 项 `confidentiality`）

四态判定口径与 v2.1 三品类基线逐字一致：

| 形态 | 判定 | note |
|---|---|---|
| 实质义务（保密要求/保密义务/应当保密/负有保密 + 实质内容；含表格跨格） | 通过 | — |
| 悬置（另行协商/待定） | 需关注 | 沿用 P2 期限判例口径 |
| 否认（无要求/不涉及/无特殊约定） | **需关注（普通档，不升 hardline）** | note 引民法典 501 条（缔约阶段兜底）+704 条口径（租赁一般内容不含保密），**不宣称 501 条对履行期间持续兜底**（#132 勘正口径） |
| 留白（字段名+冒号后整栏空白） | 未找到 + blank_flag | 固定文案同 A2 |

### 1.2 三处租赁特化的引擎设计

- **特化一（否认不升 hardline）**：否认簇词表进 `need_attention` 族（对齐 A2 P1-3
  否认簇先例），不进 hardline；pass 侧负向护栏双保险同 A2。
- **特化二（无信号 → 本类不适用，设计核心）**：新增 item 级 `signal_gate` 机制——
  引擎在该项判定前先跑信号探测（词族：`保密要求|保密条款|保密义务|保密责任|应当
  保密|负有保密|其他保密信息`），**正文+表格零命中 → status=na + note「本卷未见
  保密栏目，本类不适用」**；有命中 → 走四态。实现位置：YAML 声明 `signal_gate`
  词族，引擎 `load_checklist` 侧通用支持（不加租赁专用分支——三品类口径统一，
  将来其他 item 可复用）。fail-closed：signal_gate 词族为空/缺失时该项照常判定
  （不 na）。
- **特化三（半留白不Hon旗标）**：blank_flag 正则限定「栏目字段名后到段尾/下一字
  段前仅有空白或下划线占位，且该段无任何义务主干词」；「约定的其他保密信息即___」
  因主干含「保密信息」义务表述 → pass 命中，不Hon。与 GF-2000 整栏空壳（字段名
  不创设义务）严格区分——A1 验尸正反两用。

### 1.3 门禁（翻转白名单，裁定原文口径）

1. 15 份回放卷：仅 `lease_replay_01` 允许新增保密判定（期望=通过，无旗标）；
2. 其余 14 份：该项=本类不适用（na）；
3. **全部既有 claim 零翻转**（既有 items/scorecard 逐字段对照）。
另加：17 份官方语料回归零翻转（防 signal_gate 误伤其他品类——gate 只挂租赁新项，
理论零外溢，测试锁定）；对抗样例单测：四态各 ≥1 + 半留白 + 无信号 na + 真单方
误收防线。

### 1.4 非目标

- 不动其他 14 项；不动 NDA/采购/技术服务已回填形态；
- 不做「分诊台路由」实现（老钱明说由本设计稿定——选了 item 级 signal_gate，
  不走分诊台）；
- 不碰 F-3 引用核验（残-4：金标判定以抽取层文本为准）。

### 1.5 验收顺序

1. 对抗单测全绿 + 15 卷回放白名单门禁 + 17 份零回归；
2. ruff/pyright/全量；
3. 设计稿过审（本稿）→ 施工 → 门禁跑批 → 老钱验收（四态形态他签认过口径，
   施工结果按 v2.1 基线逐字对照）。
