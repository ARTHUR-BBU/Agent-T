> v1.2→v1.3 修订摘要（三个复现问题逐一闭环）：
> ①豁免串台调换顺序复现 → 根因是 `[^。]{0,80}` 允许链条**跨过中间的另一处命中**去接后半句的命中词（借通行证）。修法：链上加**命中词起点禁行**（tempered regex）——对等量词→免责事由→命中词之间不许出现任何其他命中的起点，链条只能绑定紧随其后的第一个命中。
> ②否定豁免被锚定挡死复现 → 根因是独立 unless 层（「不免除」3 字符）永远覆盖不了命中区间。修法：**否定前缀直接焊进命中正则**（lookbehind），否定文本根本不成为命中——比「命中后压制」更干净，且天然满足锚定。
> ③日期区间绕过护栏复现 → 根因是日期分支是独立分支没过句级护栏。修法：**日期分支并入主分支共用同一句级负护栏**（保密期限/质保期/保证期/产品有效开头整句排除）。

## 三、逐项设计（正则以原型脚本为唯一权威文本，本文摘录要点）

### ① F-2 豁免门（procurement breach:195 + NDA breach:145，hardline）

三层机制（全部经原型实跑）：

1. **否定焊进命中**：need_attention 的免除族模式加 lookbehind 前缀
   `(?<!不)(?<!未)(?<!不得)(?<!并未)(?<!不视为)免除…`——「不免除其违约责任」不再产生命中（外审复现#2 闭环：保护与命中在同一个正则里，天然绑定完整命中，无覆盖不全问题）
2. **对等豁免链（tempered chain）**：对等量词（任何一方|双方均?|各自|彼此|遇有不可抗力的一方）→【链上禁行任何其他命中起点】→ 免责事由（不可抗力|情势变更|政府行为|自然灾害|疫情）→【禁行】→ 命中词。**链条只能终止于紧随其后的第一个命中**——调换顺序复现#1 闭环：后半句单方免责借不到前半句的通行证（中间隔着「不承担违约」这个命中起点，禁行段拒绝跨越）
3. **occurrence 锚定**（unless_window: 300 + unless_anchor: true）：豁免匹配必须覆盖本次命中区间

- **分号不断链**（维持外审撤回口径）：。为唯一同句边界；「同句分号混合」用例证明分号后的单方免责照样触发（三要素链不认分号后的命中——它前面隔着免责事由句的命中起点）
- note 文案、hardline 定级、need_attention 主模式骨架不动（仅免除族加 lookbehind 前缀）

### ② payment pass 语义域（维持 v1.2，原型已全绿）

句首锚定 + 整句负护栏（违约金|赔偿|责任上限|赔偿上限|注册资本|出资 → 整句不作价款证据）；标的词含采购款；金额兜底仅在价款语境词/给付动作与金额同句时成立。金标正例「甲方收到发票后＿个工作日内将上月采购款支付给乙方」通过；四个反例（违约金按合同总价10%支付等）全拦。

### ③ term / NDA agreement_term pass 语义域（③号修复）

**日期分支与词条分支共用同一句级负护栏**（保密期限|质保期|保证期|产品有效 开头的句一律排除）——「保密期限自2026年1月1日起至2028年12月31日止」复现输入已拦 ✅；「质保期自验收合格之日起至…止」同拦。词条分支 bare「有效期/期限」不收（只认合同/协议/合同期限等复合式）。

### ④ signature：unless 补落款组 + pass 正向入口（维持 v1.2）

unless 补「法定代表人[:：]」「授权代表[:：]|委托代理人[:：]」（±60 同现窗口内生效）；pass 新增正向入口「（盖章）…法定代表人：」「法定代表人：…（盖章）」句内配对 → 通过。「供方（盖章）：法定代表人：____」✅ 通过；孤行/主体介绍反例 ✅ 不通过。
