## 三、逐项设计（含最小试跑实证）

### ① F-2 豁免门（procurement breach:195 + NDA breach:145）

**v1.1 串台根因（外审复现实锤）**：unless 只问「窗口内有没有保护文字」——正常不可抗力豁免句（对等量词+免责事由+命中词全齐）本身就构成豁免正则的一个完整匹配，落进相邻单方免责句的 ±300 窗口 → 邻居被洗白。

**v1.2 修法：occurrence 锚定**。引擎加 `unless_anchor: true`（规则级可选键）：unless 匹配必须**覆盖本次命中的区间**（match.start ≤ occ.start 且 match.end ≥ occ.end），不再只要求「落在窗口内」；配合豁免正则把命中词编进尾部，三要素（对等量词→免责事由→命中词）+本次命中必须同句共现。

```
# procurement breach / NDA breach 的 need_attention unless（主模式/hardline/note 全不动）
unless:
  # 第一层：否定语境（贴身生效）
  - "不免除|不得免除|不视为免除|并未免除"
  # 第二层：对等豁免门（unless_window: 300 + unless_anchor: true；三要素同句、命中词收尾）
  - "(任何一方|双方均?|各自|彼此|遇有不可抗力的一方)[^。]{0,150}(不可抗力|情势变更|政府行为|自然灾害|疫情)[^。]{0,80}(不承担违约|无需承担违约|免除违约责任|免除.{0,8}违约|不负违约金义务|不得主张违约金|豁免违约责任|违约责任由.{0,10}自行承担)"
```

- **分号不断链（采纳外审撤回）**：同句边界只有句号。跨分号的完整免责约定不受影响；「同句分号混合」试跑证明：分号连接的**单方免责半句照样触发**（豁免链要求三要素+命中词依次共现，单方半句没有对等量词）。
- 「遇有不可抗力的一方」补入对等量词集（MOF 18.3 实锤；bare「一方」仍**不收**——「一方违约的，免除其违约责任」是主体特定单方写法）
- 引擎改动闭环：unless 判定处读取两可选键；未设键的规则走原逻辑（窗口 60 + 仅窗口内存在即豁免），**全库其他规则行为零变化**，变异验证含此证明

### ② payment pass 语义域（含整句负护栏）

```
# 负护栏：句内含这些词，整句不构成「价款条款存在」证据（防冒充）
G = "(?![^。]{0,80}(?:违约金|赔偿|责任上限|赔偿上限|注册资本|出资))"
S = "(?:价款|货款|采购款|报酬|服务费用?|租金|对价|合同总价|合同金额|结算|费用)"
A = "(支付|付款|付清|结清|支付给)"
pass 新增（现有四条保留）:
- "(?:^|。)G[^。]{0,40}S[^。]{0,40}A"
- "(?:^|。)G[^。]{0,40}A[^。]{0,40}S"
- "(?:^|。)G[^。]{0,20}(?:价款|总价|合同金额|费用)[^。]{0,20}(?:人民币|\d+\s?元)"
```

- 句首锚定 `(?:^|。)`+`[^。]{0,40}`：护栏从句首看全句（裸 lookbehind 写法 stdlib 不支持，句首锚定等效整句负护栏）
- 正例修通关键：标的词**补「采购款」**、句首距离放宽至 40（v1.1 的 10 让「甲方收到发票后＿个工作日内…」够不着）

### ③ term / NDA agreement_term pass 语义域（保密存续期分离）

```
T = "(?:^|。)(?![^。]{0,80}(?:保密期限|质保期|保证期|产品有效))[^。]{0,12}(?:合同期限|履行期限|交付期限|供货服务期|供货期|服务期|租赁期限|租期|工期|(?:合同|协议)有效期)|(?:自[^。]{0,15}日起?[^。]{0,15}至[^。]{0,15}止)"
```

- procurement term 与 NDA agreement_term 同构套用；bare「有效期」不收、bare「期限」不收（负护栏拦保密期限/质保期/产品有效期冒充）

### ④ signature：unless 补落款组 + **pass 正向入口**（三清单）

```
# need_attention unless 补（落款行须落进盖章命中 ±60 同现窗口）
- "法定代表人[:：]"
- "授权代表[:：]|委托代理人[:：]"
# pass 新增正向入口（缺了它，取消报警后落到 missing_as 仍非「通过」——v1.1 实测教训）
- "(?:（盖章）|\(盖章\))[^。]{0,30}(?:法定代表人|授权代表|委托代理人)\s*[:：]"
- "(?:法定代表人|授权代表|委托代理人)\s*[:：][^。]{0,20}(?:（盖章）|\(盖章\))"
```

- 「供方（盖章）：法定代表人：____」→ pass 命中 → **通过**（v1.1 只取消报警、落不到通过——外审复现实锤）
- 主体介绍防线：落款组须与盖章**同句共现**（pass 模式句内配对）或落进 ±60 同现窗口（unless）；纯主体段无盖章 → 无命中 → missing_as 维持
