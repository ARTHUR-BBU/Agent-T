## 三、逐项设计（正则以原型脚本为唯一权威文本）

### ① F-2 豁免门（procurement breach:195 + NDA breach:145，hardline）

四层机制（全部经原型实跑）：

1. **单一权威命中表**：`_HIT_ALTS` 三元组（模式, 禁行起点 token, 否定敏感），主规则 pattern / 豁免链禁行段 / 豁免链终点全部从该表派生——与生产 breach 全族同源（不得追究.{0,10}违约、放弃追究、不得向.{0,8}主张违约等全部在内）
2. **否定 = occurrence 前方小上下文**：命中起点前 4 字符内出现「不|未 + 能/否/应/再/得/予」或「并未/不视为」→ 不构成命中；正则 lookbehind 仅作第一道兜底（不/未/不得/并未 直贴族）。**施工落点：引擎 occurrence 判定处实现，不再依赖 YAML 枚举**
3. **对等豁免链（tempered chain）**：对等量词（任何一方|双方均?|各自|彼此|遇有不可抗力的一方）→【链上禁行任何命中起点】→ 免责事由（不可抗力|情势变更|政府行为|自然灾害|疫情）→【禁行】→ 命中词——链条只能绑定紧随其后的第一个命中
4. **occurrence 锚定**（unless_window: 300 + unless_anchor: true）：豁免匹配必须覆盖本次命中区间

分号不断链（外审撤回口径维持）；note/hardline/主模式骨架不动。

### ② payment pass：逗号分句作用域（阻断②修复）

锚定分句头（^ 或 。；，之后）→【分句头到标的词之间禁冒充词】→ 标的词 →【禁冒充词】→ 给付动作（正向 + 反向两条）；金额兜底同分句作用域。**同句逗号之后另有违约金约定的，不再误杀前面的真实付款条款**；违约金分句自身含冒充词、被禁。

### ③ term / NDA agreement_term：词级作用域（阻断①③修复）

- 允许期限词 = 复合式（合同期限/履行期限/交付期限/供货服务期/供货期/服务期/租赁期限/租期/工期/(合同|协议)有效期）+ 泛「期限」**词级 lookbehind 排除**（保密|质保|保证|产品|保修|贮存 开头的不算）
- 词头距离放宽 `[^。，；]{0,12}`：「本协议有效期一年」这类带主语短语的正例通过；裸「有效期/期限」仍然不收
- **日期分支必须锚定允许期限词**（期限词 + ≤6 字 + 自…日…至…止）：「保密期限自…止」「质保期自…止」拦，「合同期限自…止」过

### ④ signature：unless 补落款组 + pass 正向入口（维持 v1.2/v1.3）

unless 补「法定代表人[:：]」「授权代表[:：]|委托代理人[:：]」（±60 同现窗口）；pass 新增「（盖章）…落款行」「落款行…（盖章）」句内配对 → 通过。
