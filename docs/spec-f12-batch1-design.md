## 三、逐项设计（正则以原型脚本为唯一权威文本）

### ① F-2 豁免门（procurement breach:195 + NDA breach:145，hardline）

四层机制（全部经原型实跑）：

1. **单一权威命中表（生产落地结构，阻断④修复）**：YAML 检查项新增 `hit_alternatives` 三元组结构，引擎编译函数从这一份配置派生主命中/禁行起点/豁免终点三份词表：
   ```yaml
   hit_alternatives:
     - pattern: "放弃.{0,6}追究"
       start_token: "放弃"
       neg_sensitive: true
     # …（生产 breach 全族，含 不得追究.{0,10}违约/不得向.{0,8}主张违约 等）
   ```
   正式测试调用生产编译函数；原型脚本仅作演示入口。
2. **否定 = occurrence 前方 6 字符上下文（阻断②修复）**：受限否定头（不|未）+ 连接字符集 [能可予应急再得当为会]（覆盖 不能/不会/不可/不应/不应当/不予/不再/不得/未）+ 特例 并未/不视为；**双重否定（不得不/不可不…再接命中）显式不保护**（防保护面过宽反例入断言）。正则 lookbehind 移除——避免它把双重否定提前拦掉、使上下文区分永远轮不到。施工落点：引擎 occurrence 判定处
3. **对等豁免链（tempered chain）**：对等量词（任何一方|双方均?|各自|彼此|遇有不可抗力的一方）→【链上禁行任何命中起点】→ 免责事由（不可抗力|情势变更|政府行为|自然灾害|疫情）→【禁行】→ 命中词——链条只能绑定紧随其后的第一个命中
4. **occurrence 锚定**（unless_window: 300 + unless_anchor: true）：豁免匹配必须覆盖本次命中区间

分号不断链（外审撤回口径维持）；note/hardline/主模式骨架不动。

### ② payment pass：逗号分句作用域（阻断②修复）

锚定分句头（^ 或 。；，之后）→【分句头到标的词之间禁冒充词】→ 标的词 →【禁冒充词】→ 给付动作（正向 + 反向两条）；金额兜底同分句作用域。**同句逗号之后另有违约金约定的，不再误杀前面的真实付款条款**；违约金分句自身含冒充词、被禁。

### ③ term / NDA agreement_term：词级作用域（阻断①③修复）

- **采购/NDA 词表分列**（阻断①修复）：采购 = 合同期限|履行期限|交付期限|供货服务期|供货期|服务期|租赁期限|租期|工期；NDA = 协议期限|(合同|协议)有效期；两侧共享受限泛「期限」（词级 lookbehind 排除 保密|质保|保证|产品|保修|贮存|异议|通知|缓冲|公示 开头——异议期限/通知期限不混入协议期限）
- 分句锚点统一 `[。；，,;
]`（换行/半角支持）；词头距离放宽 `[^。，；,;
]{0,12}`：「本协议期限为三年」「保密期限三年，本协议有效期一年」正例通过
- **日期分支锚定允许期限词 + 断言匹配区间覆盖完整起止**（修复 v1.4 双重拼接使日期分支从未被真实验收的 bug）：「保密期限自…止」「质保期自…止」拦，「合同期限自2026年1月1日起至2028年12月31日止」匹配覆盖全区间
