# GLM 真实链路冒烟测试报告

> 执行：开发狗（2026-09-06）。清偿遗留项「真实 Key 冒烟」。
> 环境：本地 uvicorn + `--env-file .env`，智谱 Coding 套餐 Key，`GLM_MODEL=glm-5.2`。

## 前置修复

- **启动命令缺陷**：README 原来只说「编辑 .env 填 Key」，但启动命令不带 `--env-file` 时 `.env` 根本不会被读取（991518e 修复）。选 uvicorn 原生 `--env-file` 而非 python-dotenv 自动加载：后者会在 import app 时把真 Key 注入测试进程，破坏测试隔离。
- 密钥安全：真 Key 只存 `.env`（git 已忽略），`.env.example` 模板保持空 Key。
