# Claude Code 交接：规则候选及具名审核账本

日期 2026-11-09。用户要求抓紧完成真实规则启停、具名审核、发布与回滚，允许管理员自审；依照现有安排，本机开发且暂不部署。

## 新增内容

新增 `app/services/rule_review_ledger.py`：在隔离账户库内保存经规则结构校验的候选字节、对应基线字节及完整 SHA-256，事务内由会话取得提交/审核身份；仅管理员可审核，记录理由和自审标志，普通用户只可读取自己的候选。一个候选仅能记录一次决定；对正常 SQL 更新、删除和 INSERT OR REPLACE 进行了追加保护。新增 `tests/test_rule_review_ledger.py` 覆盖权限、自审、撤权、并发、版本及追加保护。

这是底层试验，**尚未接入 API 或页面，不构成正式审核流程或发布门禁**：尚无可信自动化测试证据、审核差异页面、硬性规则约束、有效规则版本库、发布及回滚。数据库所有者可以更改触发器，不能称为防篡改审计。

独立审核发现 YAML 文件与 SQLite 不受同一事务控制；当前提交和审核时检查文件基线只能发现已发生的变化，不能阻止检查之后的并发文件变化。正式实现必须在同一可信事务中存储有效版本指针并比较切换，或采取所有写者共同遵守的跨进程协调机制；发布前还需验证候选内容、基线、测试证据及权限。旧会话、历史审查和在途长任务必须继续使用各自固定版本。

独立审核复核了候选内容读取与 REPLACE 防护；旧实验库缺少 baseline 字段时现会明确拒绝启动，不自动迁移或覆盖。账本测试及最新检查结果以本次对用户的交付报告为准。项目全量回归本轮未运行。生产身份、合同数据隔离、账户库迁移及运维恢复尚未完成，不可部署。
