# M7 新 LLM 场景四问准入面试登记（铁律 v2 程序要求，2026-10-24）

> 铁律 v2：后续任何 LLM 新场景过「四问准入面试」。本登记对应 M7 两个新场景，
> 评估依据 docs/m7/unfreeze-evaluation-20261024.md + 老钱终裁四红线
> （docs/m65/final-ruling-20261024.md）。

## 场景一：revision · 修改建议三版生成

| 四问 | 回答 |
|---|---|
| 失败降级答案是什么？ | 调用失败/解析失败/三版或必填字段不完整 → **整项降级，不展示残缺方案**（该项退回「无修改建议」态，判定层不受影响，降级留痕账本） |
| 能否变档位？ | 能——三版即三档（稳妥/平衡/进取），模板按品类档位化；不引入第四档不引入评分 |
| 可溯源吗？ | 三层留痕：原引句（locate 坐标回指原文）+修改后文本+理由；trace_id 入账本；声明文案固定（非法律意见） |
| 是否在请求路径？ | 仅在用户对已打标 item 主动展开修改建议时触发（懒加载），不在审查主路径；生成入参硬性=item 上下文，无 item 架构不可达 |

红线附加约束（终裁）：禁「建议签署/接受本条款」类表述（禁语过滤+逐例语义核对）；
禁止对未检出域生成进攻性条款；建议不回写 items_detail。

## 场景二：impact · 连带影响分析

| 四问 | 回答 |
|---|---|
| 失败降级答案是什么？ | 调用失败/解析失败 → **如实标「未覆盖」**（不伪造全覆盖结论）；判定层不受影响 |
| 能否变档位？ | 能——扫描域=相关条款簇（定位优先）；「未覆盖」即档位化的诚实态；不做全卷扫描承诺 |
| 可溯源吗？ | 每条不一致处=定位（条款索引坐标）+说明+依据引用；trace_id 入账本 |
| 是否在请求路径？ | 仅在用户选定草案（用户选定草案记录）后触发分析，不在审查主路径；纯定位+不一致报告，不生成新条款文本 |

红线附加约束：连带影响=定位与不一致报告，不验证草案生效——「采纳后是否解决问题」
以重新审查验证（与选定草案两件事，分开留痕）。
