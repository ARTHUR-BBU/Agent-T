## 四、待裁定决策点（呈老板+外审，评估不开枪）

1. **修改建议是否进 docx 报告**：现行禁令「报告 docx 不引入 LLM 生成内容」只写明质量层；M7 修改建议若进报告，docx 确定性契约需扩约（确定性来源=固定模板+已落库建议文本，不新增 LLM 调用）；若不进，则修改建议只在 Web 展示层——**建议进**（否则导出报告缺最后一环，「全链走通」打折），但需外审确认扩约口径。
2. **A/B/C 生成形态**：单次调用产三版（省费、单点截断风险）vs 三次独立调用（隔离好、费用×3）——**建议单次调用产三版**（结构化输出+Schema 校验），费用阀门按单次上限登记；开工前出费用上限单（复用 #138 机制，实测生产账本定数字）。
3. **4.2 连带影响扫描范围**：全卷扫描 vs 引用方条款簇定位——**建议条款簇定位**（stage1 索引已支持，成本可控；全卷扫描留作大合同档位另议）。
4. **修改建议的用户操作流**：采纳=仅前端展示态（用户自行复制）vs 落库生成「采纳记录」参与 4.2 触发——**建议落库**（4.2 的触发前提+可追溯），采纳操作走既有 adopt 同构接口。
