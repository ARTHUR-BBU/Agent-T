## 2. 关键观察

1. **置信度有区分度（初步）**：清晰形态 1.00、八类无家形态 0.91-0.99、真模糊（抹标题）0.74——梯度与「形态模糊度」同向；但校准集无 <0.90 样本，区分度的下界未经检验，中档路由若未来启用必须补真实样本。
2. **0.70-<0.90 档零校准样本**：中间档只有 2 条消融探针，该档的阈值行为**完全未经验证**——若未来要用该档自动路由，必须补充该置信区间的真实样本，或明确将其定位为暂定产品规则。
3. **判对≠该自动**：5 份 other 形态判对但置信 0.87-0.99，若阈值 0.90 自动展示，它们走「标注」档——恰好符合期望（拒收类建议应更谨慎）。
4. **金标纠错前后的教训**：模型 0.87 判 mandate=other 与老钱定性一致——「低置信≠判错」，路由行为按置信度分层是安全的（都弹窗或都标注，不会误导）。
