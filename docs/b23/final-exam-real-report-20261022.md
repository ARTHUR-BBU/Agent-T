## 2. 最重要的发现：低置信一致的静默盲区

3 份错题（R01 DRGs 技术服务→procurement、R13 光纤租赁→procurement、
R15 物业管理→procurement）的判定**全部等于考生的选择（procurement）**——
走的是「建议与用户一致→无感放行」路径：**置信度再低也不产生任何提示**，
合同按采购清单静默开审。对比之下，不一致路径的防线（必弹窗+低置信改文案）
在本卷全部正常工作。

这不是阅卷噪声，是设计缺口：现行设计只防「模型不同意用户」，不防
「模型和用户一起错」。候选补丁（**需用户复批，本报告不擅自施工**）：
恢复 spec-b23 v0.1 原设计——「建议一致但置信 <0.90 → 照常审查+报告头
『品类存疑』非阻断提示」。若采纳，本卷 3 份静默错题将全部转为可见存疑提示。

**残余风险如实声明**：在补丁采纳前，野样本+用户误选品类=静默按错误清单开审
（R15 场景）。「建议永不切换」红线保证模型永远不能自作主张，但保证不了
「用户选错+模型附和」的场景。

## 3. 阈值建议

**维持 0.90（高置信）/其余（低置信）现状。** 口径如实声明：0.90 是**保守的
产品策略值，不是被 15 份样本统计证明的最优值**——本卷数据的支持仅限于一
致性方向：错判上界 0.3750 距判对高置信带（0.90+）间隔显著，现行分档把本卷
全部错误拦进低置信文案。15 份样本量不足以支持更细档位拟合，也不足以做
分界点的统计估计。
