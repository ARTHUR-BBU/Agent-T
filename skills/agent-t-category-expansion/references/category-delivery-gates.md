# 新品类施工门与交付模板

## 选择轨道

| 情况 | 轨道 | 必需追加项 |
|---|---|---|
| 复用现有解析和已裁定形态，只扩展一类合同 | 最小 | 法务清单、最小金标、规则测试、精确回归门禁 |
| 新法律口径或新状态等级 | 完整 | 法务裁定、对抗集、独立复核 |
| 表格、附件、扫描件等新文本形态 | 完整 | 生产同构解析、位置证据、靶向回测 |
| 引入/更换模型或修改分诊路由 | 完整 | 冻结金标、独立留出集、预算与留痕、受控试运行 |
| 从 hidden 移除并对用户开放 | 完整 | 生产验收、用户路径、回退和开放决策 |

同一批可以包含多项，但每项都要分别说明为何需要，不因“完整轨道”而默认扩张范围。

## 开工卡最小内容

- 品类收/拒边界与相邻品类的分界。
- 检查项清单与法务裁定状态。
- 语料清单：来源、哈希、解析方式、金标来源。
- 本批允许的状态翻转表；未列入即不允许。
- 验收命令或可复现步骤。
- 明确不做的挂账，以及触发后续专项的条件。

## 测试组合

| 目标 | 应证明什么 |
|---|---|
| 正例 | 约定内容被正确识别并能给出证据 |
| 空白/悬置 | 不把模板字段或“另行协商”当作实质约定 |
| 否认/例外 | 不把否定义务或例外条款洗成通过 |
| 相邻干扰 | 普通提及、标题、金额/日期等不替错误条款背书 |
| 回归 | 只有白名单中的状态变化，其余逐项相等 |
| 生产 | 新分支真走到、相邻正例不误伤、既有确认路径不回归 |

## 证据等级

- **设计完成**：有施工卡和裁定，尚未改代码。
- **代码完成**：本地测试通过，尚未合并。
- **合并完成**：CI 通过并进入主分支，尚未部署。
- **生产验收**：受控场景在线验证，留有可复核记录。
- **正式开放**：hidden 移除或用户入口开放，且开放验收完成。

不要以较低等级替代较高等级的结论。

## 收官摘要模板

```text
位置：总路线图中的 <阶段/品类>。
本批完成：<可验证结果>。
证据：<测试、CI、生产受控验收>。
未验证：<真实样本/生产边界/尚未开放的内容>。
挂账：<明确问题与触发条件>。
下一道门：<需要谁作出什么决定或完成何项验收>。
```
